# 04:17 ｜ 七分钟重播（自由探索版）

原创悬疑 ARG 网页游戏。近未来城市渚城，2034 年 5 月 17 日凌晨 04:17，全城联网记录出现七分钟异常。
你扮演数据修复组的调查员，在一台调查终端里自由探索全部材料，自己决定先看什么、信什么——
终端不评价任何中间结论，只在最后的结案报告里一次性核对。

## 玩法结构

- **自由探索（致敬 Simulacra / Hypnospace Outlaw 的终端漫游）**：七个地点从一开始全部开放，
  没有阶段门，没有规定顺序。
- **关键词检索（致敬 Her Story / Telling Lies）**：苏晏的终端残片无法按时间浏览，
  只能用关键词调取——搜人名、物品、地点，搜不到就是搜不到。
- **三类关键材料锁，钥匙跨地点分布**：
  - 四位数字码：需要先在一处日志里完成时间验算；
  - 语义口令：答案是一个名词，线索藏在另一个人的碎片里；
  - 时序拼图：四张事件卡的真实顺序，其中一张卡的时间是假的，要靠别处材料校正。
- **结案报告（致敬 Return of the Obra Dinn 的结案确认）**：六项研判一次性提交、一次性核对，
  标明哪几项成立；不成立可改、可重交。调查完整度（材料 / 碎片收集）只展示，不拦人。
- 研判与解锁均以 SHA-256 哈希校验（非明文比对）；进度与调查笔记保存在浏览器 localStorage。

## 运行

纯静态，无构建、无依赖。用浏览器打开 `index.html` 即可；部署到 GitHub Pages 后可在线游玩。

## 文件

- `index.html` —— 终端界面与全部线索文本
- `style.css` —— 样式
- `game.js` —— 导航、检索、三类锁与结案核对逻辑
