# 04:17 ｜ 七分钟重播

原创悬疑 ARG 网页游戏。近未来城市渚城，2034 年 5 月 17 日凌晨 04:17，全城联网记录出现七分钟异常。
你扮演数据修复组的调查员，用三组互不说谎的证据，推出七分钟里真正发生了什么。

## 玩法

- 纯静态网页，无构建、无依赖、无需注册。直接用浏览器打开 `index.html` 即可游玩；
  部署到 GitHub Pages 后也可在线游玩。
- 共三个阶段：停车场抓拍日志 → 证据袋 17 → 陈述与权限。每阶段的研判都由前一阶段的证据唯一决定。
- 研判答案在本地以 SHA-256 哈希校验（非明文比对），进度保存在浏览器 localStorage 中。
- 每阶段备有多级提示；结尾有完整结案陈词。

## 文件

- `index.html` —— 页面与全部线索文本
- `style.css` —— 样式
- `game.js` —— 阶段推进与哈希校验逻辑

## 说明

本作人物、城市与事件均为虚构。游玩过程中请勿查看页面源码寻找校验值——
就像故事里的人物一样，请只相信证据。
