# 04:17 ｜ 七分钟重播

原创悬疑 ARG 网页游戏。近未来城市渚城，2034 年 5 月 17 日凌晨 04:17，全城联网记录出现七分钟异常。
你扮演数据修复组的调查员，在一台调查终端里自由探索全部材料，自己决定先看什么、信什么——
终端不评价任何中间结论，只在最后的结案报告里整份核对。

## 直接游玩

- **当前版本 v3 就在本仓库根目录**：打开 [`index.html`](index.html) 即可（纯静态、单文件、零依赖、无需注册）。
- 若已启用 GitHub Pages（Settings → Pages → Deploy from branch: `main` / root），可在线游玩根目录版本。

## 版本

| 目录 | 版本 | 形态 |
|---|---|---|
| `/`（根目录）与 `/v3` | **v3** | 自由探索＋双时间轴证据板＋“结论＋证据引用”结案核对；补齐克隆卡与审计片的证据链 |
| `/v2` | v2 | 自由探索版：终端枢纽、关键词检索、三类锁、六项研判核对 |
| `/v1` | v1 | 最初的线性三阶段版 |

## 玩法要点（v3）

- 七个以上调查地点全部开放，没有阶段顺序；三份关键材料分别被数字码、语义口令、时序拼图锁住，钥匙跨地点分布。
- 苏晏的终端残片只能用关键词检索调取（Her Story 式）；事件可在双时间轴证据板上亲手重排。
- 结案报告要求为每项结论引用已发现的材料：结论对但证据不足，不算结案。
- 进度与笔记保存在浏览器 localStorage；判定使用 SHA-256 哈希（客户端校验只为体验，不构成防作弊）。
